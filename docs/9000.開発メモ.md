## proxmox3にdeliver-stagingVMを作成する

## 手順

### proxmox3フォルダの作成

opentofu/homelab/proxmox3/フォルダを作成
### proxmox3でapiキーを発行

- proxmoxのapiキー発行
  参照：linux_memo/proxmox/proxmoxVE9.1/0050.APIキーの発行

### 発行したapiキーを使ってopentofu/secrets/proxmox3.shを作成

- opentofu/homelab/secrets/proxmox3.shでapitokenをセット

```bash
#!/usr/bin/env bash

export TF_VAR_proxmox_api_token="adminuser@pam!rundeck=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
```

- 作成したシェルスクリプトに実行権限を付与

```bash
chmod 755 opentofu/homelab/secrets/proxmox3.sh/proxmox3.sh
```

### proxmox3共通の変数をセット

- opentofu/homelab/proxmox3/env.tfvarsを作成

## templateの作成

イメージからtemplate作成しても良いし、templateをどこからかもってきてそのあとでopentofuでリソースを割り振ってもよい。

- cloudイメージから、仮想マシンテンプレートを作成し、VMを構築する
  参照: linux_memo/proxmox/proxmoxVE9.1/0410.仮想マシンテンプレートの作成
- **今回はこっち**→作成済tmplateをコピーしてVMを構築する
  参照:linux_memo/proxmox/0411.仮想マシンテンプレートのコピー
### 作成ホストのフォルダを作成

- opentofu/homelab/proxmox3/deliver-staging/フォルダを作成
- 以下のプロンプトをcodexに依頼し、構成ファイルの案を作成してもらう

```text
proxmox3にubuntu24.04で、"deliver-dev"という名前のVMを作成するopentofuの構成ファイルを、opentofu/homelab/proxmox3/deliver-dev/に作成してください。

- 構成ファイルの配置は極力opentofu/homelab/proxmo2/ubuntu2404-server-test01/と揃えてください
- porxmox3の構成は、proxmox3/env.tfvarsで定義しています。 
- deliver-devを構築するにあたり必要となるすべての設定値はユーザに訪ねてopentofuの構成ファイルを作成してください。
```

設定に必要なパラメータの確認があるので、正しく回答すると、proxmox3/deliver-dev/を作成。構成ファイルを適切に作成してくれる。
## 構成ファイルの実行

- api tokenをセットして、opentofuを実行する
  参照:  linux_memo/opentofu/0040.proxmoxにVMを作成する.md

参考までに。

```bash
# main.tfのあるopentofu/homelab/proxmox3/deliver-devで以下を実行
tofu fmt
tofu init
tofu validate
tofu plan \
  -out=deliver-dev.tfplan \
  -var-file=../env.tfvars \
  -var-file=deliver-dev.tfvars
tofu apply deliver-dev.tfplan
```

`tofu plan -out` の出力名は任意だが、本リポジトリでは `<対象名>.tfplan` に統一する。
planファイルは機密情報を含む可能性がある一時成果物のため、Gitへコミットしない。
